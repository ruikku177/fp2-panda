# FP2級 問題集アプリ

図・表のある問題では、解説下の「問題を画像で保存」で問題文・図表・四択の選択肢をPNGにまとめられます。解説に図表がある場合は解説も含めます。プレビューから保存、対応環境では画像コピー／共有ができます。文章と画像は別々にAIへ添付します。画像生成は端末内で行い、学習履歴を変更しません。画像化ライブラリは同梱のhtml2canvas 1.4.1（MIT、vendor/にライセンス）です。

> 最新更新（2026-10-19）：第6章問12・21・22・23を語群選択で出題開始。各空欄から画面下の語群を開き、選び直し・同じ語の再利用ができ、最後にまとめて採点する。現在409問を出題（第6章66問）。保留は第4章問50のみ。以下の405問・保留5問の記載は前回反映時点の記録。
> 解説下に「AIに質問（コピー）」を追加。問題・自分の回答・正解・解説をコピーして任意のAIへ貼り付ける方式。図の画像自体は含まれない。390px表示、コピー成功／手動コピー、各回答形式と演習の回帰テストを確認。

`index.html` をブラウザで開くか、このフォルダをローカルサーバーで配信して使います。学習記録とお気に入りはブラウザの `localStorage` に保存され、証券外務員アプリとは別の保存キーを使います。別のブラウザ・端末には自動同期されません。

## 収録内容

- 補助問題 第1章72問・第2章67問・第3章71問・第4章64問・第5章69問・第6章62問、計405問を出題します。第4章問50は先生への確認待ち、第6章問12・21・22・23は分数と「なし／ゼロ」の回答UI・採点表記の相談待ちで出題しません。原本の問番号は維持しています。
- 四択367問と複数選択6問は自動採点。計算・記述など残る32問も入力して自動判定します。複数欄は全欄正解でその問題を正解とします。語群に番号がある第5章問20・27・51は各欄へ語群の番号を入力。第1章問30（ウ）は「含まれます」が正解で、「含まれる」の入力も受け付けます。過去の判定保留回答は採点履歴に加えず、次回その問題を解き直せます。
- 第1章問4は（ア）〜（ウ）を複数選ぶ形式です。問5の「XXX」は記入用の空欄で、計算に必要な数値は同じページの＜資料＞にあります。
- 図は再作図済みSVG、資料表は文字表です。原本の切り出し画像は出題画面に使いません。図を押すと拡大できます。
- 模擬試験・過去問は未収録表示です。教材を受け取ってから追加します。
- 「パンダと勉強」は第1章52本、第2章16本、第3章19本、第4章25本の計112レッスンを公開。第1・3〜10回の授業範囲を、独自の説明・図表・具体例・確認問題へ再構成しています。各章の関連補助問題へ進み、問題・結果から元のレッスンへ戻れます。第2回（3級総論）は指示どおり教材化対象外、第5・6章は授業レジュメ未着につき教材作成中です。写真・スライドは公開しません。税制は2026年分の改正後を基本に説明し、旧問題はその問題の対象年・提示条件で解きます。

## 教材を追加・修正するとき

- `study-lessons.js` と `study-more-lessons.js`：従来の第1章教材。
- `study-lecture-lessons.js`：図表・レッスン生成の共通関数、第1章の追加教材、確認資料のリンク。
- `study-risk-lessons.js` / `study-finance-lessons.js` / `study-tax-lessons.js`：第2〜4章。テーマごとに、タイトル・関連問番号・重要点・説明・図表・具体例・コツ・確認問題を保持。
- `study-lecture-visuals.js`：授業原画像の図・説明を見直して作った41種類のSVG図解を48レッスンへ適用。人物関係、お金の受渡し、保障額と期間、年齢軸、面積・割合、分布などを表示。元の比較説明も折りたたんで残し、「図を拡大して見る」でスクロール可能な拡大図を開きます。図の追加に学習履歴の更新は伴いません。
- `study.js`：章ごとの目次、本文表示、次のレッスン、演習とレッスンの往復。問題ID・進捗保存キーは従来どおり。
- `study-redesign.css`：教材専用の図表・時間軸・割合バー等のスタイル。

`テスト/study-lecture-ui.cjs` で全112本の表示、320/360/390/1100px幅、関連問の存在、章別演習・レッスンへの戻り、閲覧だけでは学習履歴を更新しないことを検証します。教材数値の正しさは画面テストだけでは検証できないため、制度変更時はレッスンの参照先を確認してください。

`テスト/study-resume-visuals.cjs` は全41図の文字切れ、320/390/1100px表示、拡大・Escape・フォーカス復帰を確認します。参照した原画像と、図に残した意味は `教材下書き/レジュメ図解_照合記録.md` を参照します。画像の色・文・配置をそのまま複製せず、独自の図・架空例として作り直しています。

## 問題を追加するとき

正本は `../問題バンク/` のMarkdownです。ファイルを編集した後、`FP2級アプリ` フォルダから `python build.py` を実行すると `アプリ/data.js` が更新され、SVGも同期されます。新章を追加する場合は `build.py` の `CHAPTERS` と `アプリ/app.js` の章表示を更新してください。アプリ画面から生成済みの `data.js` を直接編集しません。

`node アプリ/test.cjs` で基本操作を確認できます。Playwrightが必要です。

法令・制度は出題当時の問題文と解説を表示しています。現行制度の確認が必要な箇所は原本・講義資料と照合してください。
