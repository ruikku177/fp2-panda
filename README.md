# FPパンダ｜FP2級 問題集

ブラウザで解けるFP2級の補助問題集。第1章72問、第2章67問、第3章71問を収録しています。

- 四択と複数選択は自動採点。計算・記述など17問も自分で入力して解答でき、すべて自動判定します。第1章問30（ウ）は「含まれます」が正解で、「含まれる」の入力も受け付けます。
- 学習記録とお気に入りはブラウザ内に保存します。端末間の同期はありません。
- 図は再作図したSVGで表示します。原本のPDFや照合用画像は、この公開リポジトリに含めません。
- 模擬試験と過去問は未収録です。
- 「パンダと勉強」は6分野の入口と第1章の9テーマ一覧を表示します。テーマ01〜03、04の住宅ローン関連、09の企業財務・カード関連、計18レッスンを公開しています。第1回授業レジュメは参考資料として使い、原本画像や文章は転載していません。

問題の正本とビルド手順はローカルの `FP2級アプリ/問題バンク/` と `FP2級アプリ/build.py` で管理しています。ここにある `data.js` は生成物です。
